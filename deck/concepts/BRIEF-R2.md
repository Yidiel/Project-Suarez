# Concept round 2 brief (refine)

Read BRIEF.md (still binding), then MARKS-R1.md. Work only on the pieces marked IN for your lane, plus ONE new replacement where your lane lost a piece (streetwear, performance, objects). Output to deck/concepts/<lane>/r2/ with the same file names (keep numbering; the replacement takes the cut slot's number with a new slug), plus r2/NOTES.md.

## The CD's new rule (hard)
"No eyebrows." Nothing on a garment or a sheet may look like a UI label: no small tracked-caps caption lines above a headline, no coordinate or elevation strings used as decoration, no label-value data blocks, no "spec sheet as aesthetic." Remove every instance from R1, including the sheet header ("VISIT SALT LAKE / CONCEPT ROUND 1 / LANE") and the spec strip styling. If the design needs data (an elevation, a year), it is the graphic itself, set large and with intent, or it is gone. Performance lane: the Gain elevation block must be rethought as a graphic, not a readout.

## What Round 2 is for
1. Push the artwork. R1 proved the idea; R2 makes it look like a thing someone would buy from Online Ceramics, Satisfy, Bode, Born x Raised. Drawing quality up: real illustration where the concept calls for it (the monster shrimp, the lotería cards, the longhorn drive, the botanical), with hand-drawn character approximated as far as SVG allows (rough strokes, varied weights, imperfect registration, halftone or grain filters) and a clear note on what a letterer or illustrator finishes.
2. Make the sheet feel like a lookbook page, not a tech pack: garment large, graphic detail blown up in an inset, colorways as swatches with names, a short caption in plain sentences. The spec goes to NOTES.md, not the sheet.
3. Keep three real choices per piece where the CD asked for options: the hoodie runs as a three-phrase drop (NOTHING TO DO IN SALT LAKE, SALT LAKE IS FOR THE WEIRD, POSERS GO TO PARK CITY) in three colorways; show all three.
4. Spec in NOTES.md: blank or maker, fabric, technique, placement and size, colorways, estimated unit cost tier at a 50-unit test run (use research/merch/05-production-logistics-and-audience.md), and the one thing to verify before sampling.

Validate every SVG with minidom. Report back the file list and one line per piece.
