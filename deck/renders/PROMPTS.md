# VSL merch deck: Round 1 render prompts

For the Mac session driving Chrome. Generate each piece in all three tools where noted. Save renders as `deck/renders/<id>-<tool>.png` (for example `S1-mj.png`, `S1-gpt.png`, `S1-gemini.png`). Pick the best variant per tool; one file each is enough for Round 1.

## Rules for every prompt
- Do not render any Olympic rings, the word Olympic, "2034," Ski Utah marks, the "Greatest Snow on Earth" slogan, or the Utah state flag.
- Do not render the Visit Salt Lake logo. Leave logo placement blank; it gets comped in later. Where a mark is needed, describe it as "a small irregular salt-crystal line icon."
- Text on garments must be short and exact as written. If a tool garbles text, re-run once, then accept and note it.
- No people unless the prompt says so. Flat-lay or ghost-mannequin product shots on a Cream (#F6F1EC) seamless, soft natural window light, slight film grain, catalog style (think Aimé Leon Dore, Satisfy, Arc'teryx product pages). Square-ish 4:5.

## Shared style preamble (paste before each tool prompt)
**Midjourney:** `premium apparel product photography, flat lay on warm cream seamless paper, soft north window light, subtle film grain, muted editorial color, shallow depth, catalog style --ar 4:5 --style raw --v 7`
**ChatGPT (GPT image):** "Premium apparel product photograph, flat lay on a warm cream seamless backdrop, soft natural window light, subtle film grain, editorial catalog look, no people, no watermarks, no extra logos."
**Gemini:** same as ChatGPT, plus "render text exactly as written and keep it small and legible."

## Tool notes
- Midjourney: use `--v 7 --style raw`. If text fails, add `--q 2` or use the editor to re-render the text region.
- ChatGPT: ask for 1024 x 1280 or "portrait, high quality." It handles text and embroidery detail best; use it as the reference for text accuracy.
- Gemini: good for fabric realism; expect weaker text, accept and note.
